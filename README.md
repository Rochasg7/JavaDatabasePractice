# Introdução a Banco de Dados com Java

Este repositório contém os projetos e exercícios desenvolvidos durante as aulas da faculdade sobre **integração de banco de dados com Java**.

O objetivo é aprender os conceitos básicos de bancos de dados e como realizar a comunicação entre uma aplicação Java e um banco de dados.

## 📚 Conteúdos estudados

* Conceitos básicos de Banco de Dados
* SQL
* Criação e manipulação de tabelas
* `INSERT`, `SELECT`, `UPDATE` e `DELETE`
* Conexão entre Java e Banco de Dados
* JDBC
* Operações de CRUD
* Integração de aplicações Java com banco de dados

## 🛠️ Tecnologias utilizadas

* Java
* JDBC
* SQL
* Eclipse
* Git e GitHub

## 🎓 Objetivo

Este projeto tem finalidade **acadêmica**, sendo utilizado para praticar e acompanhar o aprendizado da disciplina de Banco de Dados e sua integração com Java.
